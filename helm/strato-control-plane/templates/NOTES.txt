1. Get the application URL by running these commands:
{{- if .Values.gateway.enabled }}
  https://{{ include "strato-control-plane.gateway.webHost" . }}
  (Gateway API / Envoy Gateway — TLS terminated at the Gateway on :443)
{{- else if .Values.frontend.enabled }}
  echo "Visit http://127.0.0.1:8080 to use Strato"
  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "strato-control-plane.fullname" . }}-frontend 8080:{{ .Values.frontend.service.port }}
{{- else if contains "NodePort" .Values.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "strato-control-plane.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo "The frontend is disabled; the control-plane API is available at:"
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "LoadBalancer" .Values.service.type }}
     NOTE: It may take a few minutes for the LoadBalancer IP to be available.
           You can watch the status of by running 'kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "strato-control-plane.fullname" . }}'
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "strato-control-plane.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo "The frontend is disabled; the control-plane API is available at:"
  echo http://$SERVICE_IP:{{ .Values.service.port }}
{{- else if contains "ClusterIP" .Values.service.type }}
  echo "The frontend is disabled; port-forward the control-plane API:"
  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "strato-control-plane.fullname" . }} 8080:{{ .Values.service.port }}
{{- end }}

3. Authorization:
   - Handled by the control plane's built-in Cedar policy engine (no external
     authorization service is deployed).

4. WebAuthn Configuration:
   - Relying Party ID: {{ .Values.strato.webauthn.relyingPartyId }}
   - Relying Party Name: {{ .Values.strato.webauthn.relyingPartyName }}
   - Origin: {{ include "strato-control-plane.webauthnOrigin" . }}

5. Database migrations:
   - Every control-plane pod applies pending migrations before it listens for
     traffic. An advisory lock serializes concurrent replicas.
   - A migration failure leaves the new pod unready and is reported in its logs.

6. To connect Strato Agents to this control plane:
   {{- if .Values.gateway.enabled }}
   - Agent WebSocket (SVID mTLS via SNI passthrough):
     wss://{{ include "strato-control-plane.gateway.agentsHost" . }}/agent/ws
   - SPIRE node attestation (SNI passthrough): {{ include "strato-control-plane.gateway.spireHost" . }}:443
   {{- else }}
   - Expose wss://agents.<host>/agent/ws with TLS passthrough to the
     {{ include "strato-control-plane.fullname" . }} Service's agent-mtls port
     ({{ .Values.spire.envoy.agentPort }}). Do not terminate TLS before the Envoy
     sidecar; it must receive and verify the agent's SVID client certificate.
   {{- end }}

7. Health Checks:
   - Control Plane Health: kubectl get pods -l app.kubernetes.io/name={{ include "strato-control-plane.name" . }}
{{- if .Values.postgresql.enabled }}
   - PostgreSQL Health: kubectl get pods -l app.kubernetes.io/name=postgresql
{{- end }}

8. Troubleshooting:
   - View logs: kubectl logs -l app.kubernetes.io/name={{ include "strato-control-plane.name" . }}
   - Describe pod: kubectl describe pod -l app.kubernetes.io/name={{ include "strato-control-plane.name" . }}
   - Check events: kubectl get events --sort-by=.metadata.creationTimestamp

{{- if has "X25519MLKEM768" .Values.spire.envoy.tlsParams.ecdhCurves }}

🔒 Post-quantum key exchange:
   The Envoy mTLS sidecar prefers X25519MLKEM768 (hybrid ML-KEM-768) for
   agent connections, so recorded handshakes stay confidential against a
   future quantum attacker. Agents negotiate it automatically from
   swift-nio-ssl 2.37.1 onward; older agents fall back to X25519 and keep
   working.

   This group requires Envoy >= v1.39.0 (configured tag: {{ .Values.spire.envoy.image.tag }}).
   On an older Envoy the sidecar fails to start with "Failed to initialize
   ECDH curves" and agents lose the control channel — in that case remove
   X25519MLKEM768 from spire.envoy.tlsParams.ecdhCurves.
{{- end }}
{{- end }}
